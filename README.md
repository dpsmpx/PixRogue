PixelRogue

Классический Rogue в пиксельном стиле.

Игра выполнена в вертикальной портретной ориентации и поддерживает адаптивную раскладку под любой размер экрана, сенсорную экранную клавиатуру и физическую клавиатуру.

📜 Особенности

- Чистый пиксельный стиль — игровая карта отображается только цветными квадратами, без ASCII-символов. Текст используется только в служебных панелях: сообщениях, статусе и клавиатуре.
- Классические механики Rogue:
  - 26 уровней подземелья
  - Амулет Йендора
  - голод
  - опыт и уровни
  - класс брони
  - случайная генерация уровней
  - туман войны
  - ловушки
  - идентификация предметов через их использование
- Монстры со специальными атаками — паралич, кража золота и предметов, ржавление брони, высасывание жизни, дыхание огнём и многое другое.
- Случайные обличья предметов — зелья, свитки, кольца и жезлы имеют случайные названия и внешний вид. Их свойства приходится узнавать непосредственно во время игры.
- Управление на телефоне и ПК:
  - экранная клавиатура из 28 кнопок
  - крестовина движения
  - основные действия
  - управление снаряжением
  - автоповтор движения при удержании кнопки
  - автоматическая остановка перед врагом
  - поддержка физической клавиатуры
- Адаптивная раскладка — интерфейс рассчитывается исходя из реального размера окна. Игра может работать как на смартфоне, так и в оконном режиме на ПК.
- Энергоэффективность — перерисовка выполняется только при изменении состояния игры, например после события или игрового хода.

🔧 Требования

- Python 3.6 или новее
- Pygame 2.x

Установка Pygame

pip install pygame

---

🚀 Запуск

1. Клонирование репозитория

git clone https://github.com/dpsmpx/PixRogue.git
cd PixRogue

2. Запуск игры

python main.py

На ПК игра открывается в окне с пропорциями 20:9, аналогичными экрану смартфона.

Размер окна можно изменять — интерфейс автоматически адаптируется под новое разрешение.

🎮 Управление

📱 Экранная клавиатура

Экранная клавиатура состоит из пяти рядов.

Крестовина движения

Слева расположена крестовина 3×3:

- 8 направлений движения
- центральная кнопка — Ждать, чтобы пропустить ход

Основные действия

Справа расположена панель основных действий:

Кнопка| Действие
Вниз >| Спуститься по лестнице
Вверх <| Подняться по лестнице
Искать| Искать скрытые ловушки
Инвент.| Открыть инвентарь
Пить| Выпить зелье
Читать| Прочитать свиток
Жезл| Использовать жезл
Есть| Съесть еду
Справка| Открыть справку

Снаряжение и системные команды

Кнопка| Действие
Метнуть| Метнуть оружие
Бросить| Бросить предмет
Оружие| Взять оружие в руки
Броня| Надеть броню
Снять броню| Снять броню
Кольцо| Надеть кольцо
Снять кольцо| Снять кольцо
Отмена| Отменить текущий выбор
Заново| Начать новую игру
Выход| Выйти из игры

Выбор предмета

Предмет выбирается тапом по соответствующей строке списка.

Для использования жезла или метания предмета сначала выберите предмет, а затем укажите направление с помощью крестовины.

🏆 Цель игры

Спуститесь на 26-й уровень, найдите Амулет Йендора, а затем поднимитесь обратно к выходу на первом уровне.

По пути вам предстоит:

- сражаться с монстрами
- исследовать случайно генерируемые подземелья
- избегать ловушек
- управлять голодом
- находить полезные предметы
- определять свойства неизвестных предметов
- сохранять жизнь как можно дольше

---

⚔️ Основные механики

Бой

Атака происходит при попытке переместиться на клетку, занятую монстром.

Шанс попадания зависит от характеристик игрока и противника, включая уровень, силу и класс брони.

⭐ Опыт и уровни

За убийство монстров игрок получает опыт.

Повышение уровня увеличивает максимальное количество здоровья и улучшает возможности персонажа.

🍖 Голод

Со временем персонаж начинает голодать.

Еда восстанавливает сытость, а кольцо медленного пищеварения замедляет расход еды.

🧪 Предметы

В игре встречаются:

- зелья
- свитки
- кольца
- жезлы
- оружие
- броня
- еда

Большинство магических предметов имеют случайное обличье. Например, вместо описания эффекта игрок может увидеть только название вроде «алое зелье».

Свойства неизвестных предметов необходимо определять экспериментальным путём.

☠️ Проклятия

Некоторые предметы могут оказаться проклятыми:

- оружие может прилипнуть к руке
- броню может быть невозможно снять
- кольцо может отказаться сниматься

Для снятия проклятий используется соответствующий свиток.

🪤 Ловушки

Подземелья содержат различные ловушки:

- люки
- дротики
- капканы
- телепорты
- другие опасности

Ловушки можно обнаруживать с помощью действия «Искать» или специальных предметов.

🌫️ Туман войны

Исследованные области сохраняются на карте, однако неисследованные участки остаются скрытыми.

В тёмных комнатах видимость ограничена.
