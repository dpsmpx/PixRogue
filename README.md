# PixelRogue

**Классический Rogue (1980) в пиксельном стиле — вертикальный экран, сенсорное управление, один файл без зависимостей кроме Pygame.**

[![Python](https://img.shields.io/badge/Python-3.6%2B-blue?logo=python&logoColor=white)](https://www.python.org/)
[![Pygame](https://img.shields.io/badge/Pygame-2.x-orange)](https://www.pygame.org/)
[![Platform](https://img.shields.io/badge/Platform-Android%20%7C%20Windows%20%7C%20Linux-lightgrey)](#-запуск)
[![License](https://img.shields.io/badge/License-GPLv3-green)](LICENSE)

Подземелье из 26 уровней, Амулет Йендора, голод, проклятые предметы и монстры,
которые крадут ваше золото. Карта рисуется **только цветными квадратами** —
никаких ASCII-символов.

## 📜 Особенности

### Чистый пиксельный стиль

Игровая карта состоит исключительно из цветных квадратов. Текст присутствует
только в служебных зонах — строке сообщений, панели статуса и на клавиатуре.
Эти зоны рассчитаны так, что **никогда не перекрывают игровое поле**.

### Классические механики Rogue

| Механика | Реализация |
| --- | --- |
| Подземелье | 26 уровней, случайная генерация по сетке комнат 3×4 |
| Цель | Амулет Йендора на 26 уровне + возвращение к выходу |
| Персонаж | HP, Сила, Опыт и уровни, Класс брони (AC), Золото |
| Голод | Сыт → Голоден → Слаб → Теряет силы → Голодает |
| Туман войны | Освещённые комнаты видны целиком, тёмные — по соседним клеткам |
| Ловушки | 6 типов, скрыты до обнаружения поиском |
| Идентификация | Свойства предметов узнаются только через применение |

### Содержимое

- **25 видов монстров** со спец-атаками: паралич взглядом, кража золота и
  предметов, ржавление брони, высасывание силы, опыта и максимального здоровья,
  дыхание огнём, регенерация, удержание на месте, невидимость.
  Состав населения зависит от глубины.
- **15 зелий**, **13 свитков**, **12 колец**, **13 жезлов**, **10 видов оружия**,
  **8 видов брони**.
- **Случайные обличья.** В каждой партии зелья, свитки, кольца и жезлы получают
  новые случайные названия: «алое зелье», свиток «ВЕНИБАШ», «топазовое кольцо».
  Что это на самом деле — придётся выяснять на себе.
- **Проклятия.** Оружие прилипает к руке, броня не снимается, кольцо не желает
  сходить с пальца. Лечится свитком снятия проклятия.

### Управление на телефоне и ПК

- Экранная клавиатура из **28 кнопок**: крестовина движения, основные действия,
  снаряжение, системные команды.
- Автоповтор шага при удержании крестовины, с **автоматической остановкой**,
  если рядом появился враг или персонаж получил урон.
- Выбор предмета — тап прямо по строке списка.
- Физическая клавиатура работает параллельно: стрелки, NumPad и раскладка
  `hjkl` + `yubn` в духе оригинала.

### Адаптивная раскладка

Интерфейс рассчитывается от реального размера поверхности при запуске.
Проверено на 1080×2400, 1080×2260, 1080×2160, 720×1600, 1440×3200 и в оконном
режиме на ПК — зоны нигде не пересекаются, кнопки не наезжают друг на друга и
не заходят на карту.

### Энергоэффективность

Игра пошаговая, поэтому кадр перерисовывается только при изменении состояния —
после ввода или хода. В простое цикл не тратит ресурсы на бессмысленный
рендеринг, что заметно экономит батарею на телефоне.

## 🔧 Требования

- **Python 3.6+**
- **Pygame 2.0+** — версия 2 обязательна: используется параметр `border_radius`,
  которого нет в Pygame 1.x

Код не использует f-строки и синтаксис новее 3.6, поэтому нижняя граница версии
Python определяется требованиями самого Pygame.

```bash
pip install pygame
```

## 🚀 Запуск

### 📱 Android — Pydroid 3

1. Установите **Pydroid 3** из Google Play.
2. Откройте встроенный **Pip** и установите пакет `pygame`.
3. Скопируйте `main.py` в память устройства, откройте его в Pydroid 3 и нажмите
   кнопку запуска.

Игра рассчитана на **вертикальную ориентацию экрана**. Раскладка подстраивается
под ту область, которую выделит Pydroid 3.

### 💻 ПК — Windows, Linux, macOS

```bash
git clone https://github.com/dpsmpx/PixRogue.git
cd PixRogue
python main.py
```

На ПК открывается окно с пропорциями 20:9, повторяющее экран смартфона.

> **Замечание.** Размер окна определяется один раз при запуске и подстраивается
> под разрешение экрана. Изменение размера окна мышью во время игры не
> обрабатывается — чтобы получить другой размер, перезапустите игру.

## 🎮 Управление

### 📱 Экранная клавиатура

Клавиатура занимает пять нижних рядов и разбита на три блока.

#### Крестовина движения (слева, 3×3)

Восемь направлений, включая диагонали. Центральная кнопка — **Ждать**
(пропуск хода). Удержание кнопки направления включает бег.

```
[  1  ] [  2  ] [  3  ]      1 2 3 — вверх-влево, вверх, вверх-вправо
[  4  ] [Ждать] [  6  ]      4   6 — влево, вправо
[  7  ] [  8  ] [  9  ]      7 8 9 — вниз-влево, вниз, вниз-вправо
```

#### Основные действия (справа, 3×3)

| Кнопка | Действие |
| --- | --- |
| `Вниз >` | Спуститься по лестнице |
| `Вверх <` | Подняться по лестнице |
| `Искать` | Искать скрытые ловушки рядом |
| `Инвент.` | Открыть инвентарь |
| `Пить` | Выпить зелье |
| `Читать` | Прочитать свиток |
| `Жезл` | Взмахнуть жезлом |
| `Есть` | Съесть еду |
| `Справка` | Открыть справку с легендой цветов |

#### Снаряжение и системные команды (внизу, 5×2)

| Кнопка | Действие |
| --- | --- |
| `Метнуть` | Метнуть оружие |
| `Бросить` | Выбросить предмет на пол |
| `Оружие` | Взять оружие в руки |
| `Броня` | Надеть броню |
| `Снять броню` | Снять броню |
| `Кольцо` | Надеть кольцо (максимум два) |
| `Снять кольцо` | Снять кольцо |
| `Отмена` | Отменить текущий выбор |
| `Заново` | Начать новую партию |
| `Выход` | Выйти из игры |

#### Выбор предмета

Предмет выбирается **тапом по строке списка**. Для жезла и метания сначала
выбирается предмет, затем направление крестовиной. Центральная кнопка
крестовины в этот момент работает как отмена и не тратит заряд или снаряд.

Кнопки, недоступные в текущем режиме, автоматически гаснут.

### ⌨ Физическая клавиатура

| Клавиша | Действие |
| --- | --- |
| `h` `j` `k` `l` | Движение: влево, вниз, вверх, вправо |
| `y` `u` `b` `n` | Движение по диагонали |
| Стрелки | Движение |
| NumPad `1`–`9` | Движение, включая диагонали |
| `.` или NumPad `5` | Ждать, пропустить ход |
| `>` | Спуститься по лестнице |
| `<` | Подняться по лестнице |
| `s` | Искать ловушки |
| `i` | Инвентарь |
| `?` | Справка |
| `q` | Выпить зелье |
| `r` | Прочитать свиток |
| `z` | Взмахнуть жезлом |
| `e` | Поесть |
| `t` | Метнуть оружие |
| `d` | Выбросить предмет |
| `w` | Взять оружие в руки |
| `W` | Надеть броню |
| `T` | Снять броню |
| `P` | Надеть кольцо |
| `R` | Снять кольцо |
| `a`–`z` | Выбор предмета в открытом списке |
| `Esc` | Отменить выбор или закрыть окно |

> **Важно.** Физический NumPad работает в своей обычной ориентации: `7` `8` `9` —
> верхний ряд (вверх-влево, вверх, вверх-вправо), `1` `2` `3` — нижний.
> Цифры на экранной крестовине пронумерованы в порядке чтения, сверху вниз,
> поэтому одна и та же цифра на экране и на NumPad означает разные направления.

## 🏆 Цель игры

Спуститься на 26-й уровень подземелья, забрать **Амулет Йендора** и подняться
обратно к выходу на первом уровне. Без амулета выход наверх закрыт.

По пути предстоит сражаться с монстрами, обходить ловушки, следить за голодом и
опытным путём выяснять, что делает очередное «мутное зелье».

## 🎲 Механики

### Бой

Атака выполняется движением на клетку, занятую монстром. Шанс попадания зависит
от уровня опыта, силы, зачарования оружия и класса брони противника.

Раненые агрессивные монстры могут обратиться в бегство.

### Опыт и уровни

За убитых монстров начисляется опыт. Повышение уровня увеличивает максимальное
здоровье и шанс попадания.

### Класс брони (AC)

Как в оригинале: **чем меньше число, тем лучше защита.** Стартовый кольчужный
доспех `+1` даёт AC 6, латы `+2` — AC 1.

### Голод

Пища расходуется каждый ход. Кольцо медленного пищеварения замедляет расход,
кольцо регенерации — наоборот, ускоряет. При полном истощении персонаж начинает
терять сознание, а затем и здоровье.

### Ловушки

Люк, телепорт, дротиковая ловушка, усыпляющий газ, медвежий капкан и ржавая
ловушка. До обнаружения ловушки невидимы; ищутся кнопкой `Искать` или пассивно
кольцом поиска. Левитация позволяет пройти над механическими ловушками.

### Туман войны

Исследованные участки остаются на карте приглушённым цветом. Освещённая комната
видна целиком при входе, тёмная — только на расстоянии одной клетки.
Свиток карты уровня раскрывает всю планировку, свиток света освещает комнату.

## 🔀 Отличия от оригинального Rogue

Сделаны сознательно и перечислены честно:

- **Нет ключей и запертых дверей** — их не было и в оригинале.
- **Уровни сохраняются** при возвращении. В оригинале уровень генерировался
  заново; здесь это удобнее и позволяет прятать запасы еды.
- **Монстры ходят строго пошагово** — мир движется только когда ходите вы.
  Исключение: ускорение зельем даёт лишний ход.
- **Ловушки видны после обнаружения** и не исчезают со временем.
- **Бег** (удержание кнопки) сам останавливается у врага — на телефоне это
  необходимость, а не поблажка.

## 🔩 Настройка под свой экран

Все размеры интерфейса выводятся из одного числа — высоты кнопки.
Класс `Layout`:

```python
# было: кнопка ≈ 7.3 мм на экране 1080×2400 (~395 ppi)
self.btn_h = max(22, round(w * 0.106))
```

- **Кнопки великоваты, хочется больше карты** — уменьшите коэффициент до `0.095`.
- **Не попадаете пальцем** — увеличьте до `0.115`.

Прочие полезные константы в начале файла:

| Константа | Значение | Что делает |
| --- | --- | --- |
| `MAP_COLS`, `MAP_ROWS` | `40`, `50` | Размер карты в клетках |
| `GRID_COLS`, `GRID_ROWS` | `3`, `4` | Сетка комнат при генерации |
| `MAX_DEPTH` | `26` | Глубина подземелья |
| `HOLD_DELAY` | `420` | Задержка до начала бега, мс |
| `HOLD_REPEAT` | `150` | Интервал шагов при беге, мс |
| `FPS` | `30` | Верхний предел частоты кадров |

## 🧠 Как устроен код

Игра умещается в один файл и разделена на смысловые блоки:

| Блок | Назначение |
| --- | --- |
| Константы и таблицы | Палитра, предметы, монстры, ловушки |
| `Item`, `Monster`, `Room`, `Level` | Модель данных |
| `Layout` | Расчёт всех прямоугольников интерфейса от размера окна |
| `RogueGame` — генерация | Комнаты по сетке, коридоры, двери, население |
| `RogueGame` — правила | Бой, предметы, эффекты, голод, ИИ монстров |
| `RogueGame` — ввод | Единый диспетчер `command()` для тача и клавиатуры |
| `RogueGame` — отрисовка | Карта, панели, окна, клавиатура |

Тач и физическая клавиатура сведены в один метод `command(cmd, arg)`, поэтому
любое действие имеет ровно одну реализацию независимо от способа ввода.

Генерация уровня использует сетку ячеек: в каждой размещается комната, ячейки
связываются остовным деревом со случайным обходом плюс несколько лишних рёбер.
Такой подход исключает наложение комнат и гарантирует, что все лестницы
достижимы.
