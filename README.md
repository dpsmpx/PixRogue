# PixelRogue

Классический Rogue в «пиксельном» стиле.  
Вертикальная портретная ориентация, адаптивная раскладка под любой экран, полноценная сенсорная клавиатура и поддержка физической клавиатуры.

## 📜 Особенности

- **Чистый пиксельный стиль** — карта отображается только цветными квадратами, без ASCII-символов. Текст присутствует лишь в служебных панелях (сообщения, статус, клавиатура) и никогда не перекрывает игровое поле.
- **Классические механики Rogue**: 26 уровней подземелья, Амулет Йендора, голод, опыт, класс брони, случайная генерация уровней, туман войны, ловушки, идентификация предметов по использованию.
- **Монстры со специальными атаками**: паралич, кража золота и предметов, ржавление брони, высасывание жизни, дыхание огнём и многое другое.
- **Случайные «обличья» предметов** — зелья, свитки, кольца и жезлы выглядят по-разному в каждой партии, их свойства нужно опознавать на практике.
- **Управление для телефона и ПК**:
  - Большая экранная клавиатура из 28 кнопок (крестовина движения, основные действия, снаряжение).
  - Автоповтор шага при удержании кнопки движения (с автоостановкой у врага).
  - Полная поддержка физической клавиатуры: vi-клавиши (`hjklyubn`), стрелки, цифровая клавиатура, горячие клавиши для действий.
- **Адаптивная раскладка** — интерфейс рассчитывается от реального размера окна, поэтому игра отлично работает как на смартфонах (например, Redmi Note 13 1080×2400), так и в оконном режиме на ПК.
- **Энергоэффективность** — рендеринг только при изменении состояния (событие или ход), экономит батарею на мобильных устройствах.
